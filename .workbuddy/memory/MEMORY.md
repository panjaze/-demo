## 项目协作约定（与用户级记忆互补）
- 用户是游戏策划，**数值合理性全部由 AI 分析调整**，用户只做规则层设计决策
- 不擅自扩展范围；新功能须能强化「抽卡建城」或「战争改变经营」，否则第一版不做
- **不要虚报「冲突」**：数值待定、不同对象的并行规则、新增要求都不算矛盾，用户会逐条核对
- 跑批胜负对脚本策略极敏感（曾 0%↔95% 三轮摆动），**AI 真实强度只有实机能验**
- 高频 bug 源：双方对称性（新规则必写 p1/p2 双向断言）；兵力账本口径（`activeTroops` = 场上+空中，才是上限唯一正确口径）；AI 走捷径绕过玩家路径（placeRoad / 耗粮 / 政策，都曾漏接）
