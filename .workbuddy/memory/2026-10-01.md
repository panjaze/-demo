## 铺路视觉「开垦官道」效果对比（用户质问铺路仍是方块后的回应）

- **用户质问**：为什么铺路仍是正方形方格，说好的"开垦原先官道"？
- **根因确认**：官方道开垦当时只落在底图（retex 旧径）+ 数据层（officialRoads 99 格 + AI 优先），`sandbox.js drawRoads()` 渲染层从未接上——铺路仍是 `fillRect` 不透明方块（fill #8a7355，占格 56%）盖在底图上，与底图纹理零关系。
- **本次产出（均在 `图片素材/美术风格测试/`，未动 demo 代码）**：
  - `make_road_reclaim.py`：用 **final 与 retex 逐像素差值**定位真实路面（HSV 阈值法误判 52.9% 地形，已弃），生成 `road-reclaim.png`（1740×900 透明层，官道格贴回=开垦）+ `road-stamp-h/v.png`（60×60 横/竖路面材质）。
  - `road-preview.html` + `serve_compare.js` + `shot_road_preview.js`：四方案同路线对比页（现状/A/B/D），playwright+Chrome 截图 `铺路表现对比-2026-10-01.png`。
- **四方案**：
  - 现状：不透明方块（问题本尊）。
  - A 素材开垦：官道格贴回清晰官道（严丝合缝），非官道格贴 stamp；最贴合"开垦"，远看偏淡。
  - B 混合叠加：圆头带状路（沿连接方向，宽 0.44T）+ multiply/color/soft-light/lighten 混合栈，底图纹理透出；**配比经无头 Chrome 像素实验标定**：multiply #6b5840 α.13 → color #cdb388 α.88 → soft-light #e0cc9c α.30 → lighten #d9c493 α.22，落点 rgb(163,143,91)，目标=贴回素材均值 rgb(166,150,90)。

- **坑**：① cv2.imwrite 中文路径失败 → imencode+tofile；② 无头 Chrome 缓存 HTML（加 ?v=Date.now() 破缓存，用 DEBUG 红块验证链路）；③ canvas 'color' 混合在高亮草底上会掉饱和（kaki 灰绿），需 soft-light 补。

## 方案 A+B 落地 + 素材重做（用户拍板「先做成A+B」后，第三十九次修订）

- **第一版 A+B 上机后被像素采样打脸**：`13,8 / 14,8 / 15,8` 三格路心色差 Δ≈2（等于没画）。原因：设计时让「官道↔官道且都有素材」的段跳过带状路、只贴素材，素材一有缺陷就断头。
- **★ 素材 v1 根本就是错的**（已实证，务必记住）：`plate-final` 与 `plate-retex` 的差异**不只是路面**，整片草地也被动过重做纹理 → 差值掩膜在 (3,9) 是一整块 **~80% 覆盖的斑块**，逐格取最大连通域就把这块斑当成路。贴回去＝把用户嫌弃的方块换成软边版本。**横截面采样**证实真实官道在格里只有 **~15px 宽（≈25% 格宽）且不居中**。
- **新品 `make_road_reclaim2.py`（取代 v1，v1 已标注废弃）**：① 用官道坐标表画 34px 宽走廊（限制搜索范围，避开遍野枯黄草）→ ② 走廊内 `R-G` 打分 + Otsu 自动阈值认路面 → ③ 全图剔 <600px 的小连通域 → ④ 逐格取最大连通域，**按质心平移把路条归位到格心**（否则 15px 的路条偏在格子一侧，跟相邻带状路拧着）→ ⑤ 覆盖率 <8% 或 >50% 判废（>50% 的是底图本就有的大片空地/路口广场，如 (8,6)=93%、(27,5)=82%，单独一格铺路露出一大片土场）。产出 **97 格中 56 格**，其余自动退化为带状路。
- **渲染层改动 `js/sandbox.js`**：
  - `buildReclaimCells()` 由布尔改为**存覆盖率**，只有 [8%,55%] 才允许贴回（素材缺陷的最后一道闸）。
  - `drawRoads()`：**所有路格都先画带状路**（官道格也不例外），素材只是叠上去加还原感 → 任何一格都不会断头。
  - 新增**桥两边补半段**：桥（水格）不画路面露 intended，但四向都要检查对水邻居接半段到岸边——只往右/下连会导致桥"对面"那侧没人接（实测踩过：一开始只补了西侧，东岸又断）。
- **验证方式升级（可复用）**：`test/_roadvisual_verify.js` —— 同一相机同一批采样点，铺路前后各采一次算色差：路心 Δ≥25（画出来了）、相邻格中点 Δ≥20（没断成一节节胶囊）、**垂直路肩 Δ≤22（没铺满整格＝不再方块）**、桥格豁免。`test/_roadvisual_shot.js` + `compose_road_compare.py` 出对照图。
- **结果**：49/49 断言通过；官道格与纯新建支路路心最终色均值 **rgb(174,152,111) vs (175,151,101)，色差仅 10**（观感一致）；路面有效宽度实测 **≈45% 格宽**、边缘软过渡。`node test/run.js` 四层全绿，控制台 0 报错。
