**踩坑更新**：
5. **ImageGen 的 `background: transparent` 无效**（返回 RGB），纯色背景 + 流水线抠图才是正路
6. **并行调用 ImageGen 会互相覆盖**（文件名按秒级时间戳）——必须串行生成，出图后立即重命名
7. **抠图不能只靠颜色距离**：兵营原图有全局羊皮纸晕染，纯颜色阈值会把建筑啃掉一半；主判定用「与背景均值距离 ≤60」，梯度扩散只允许吃"仍像背景"的像素（≤78）
8. **提示词要明确"禁止拆解图/多视图/虚线框"**——主城曾被画成组件分解图（左侧主体可裁切抢救，但别赌）
9. **PIL 的 ImageDraw 在 RGBA 图上是替换像素不是透明混合**：`fill=(r,g,b,20)` 会在 `convert('RGB')` 后变成实心亮色块——半透明元素必须画在独立图层再 `alpha_composite`
10. 底板尺寸给 **1536×800**（接近地图 1.93 宽高比）完全可行，不必局限 1024 方图

## 1. 任务背景与目标

把游戏从"程序 Demo / 网页工具感"转变成"一款真正完整的策略桌游式游戏"。**统一性优先于单张惊艳**：所有资产必须同一世界观、同一绘画方式、同一视角（俯视 3/4）、同一光照逻辑（左上光源）、同一材质语言。

三条硬规则：
1. **不把中文、数字、等级、成本生成进插画**——文字全部由游戏 UI 层叠加
2. 不要人物作为主体、不要大规模军队、不要复杂战场
3. 不要科技蓝 / 紫蓝渐变 / 玻璃拟态 / 赛博朋克 / 霓虹 / 现代后台风

## 4. ★ 风格锁 Prompt 模板（批量生成时直接复用）

**共用基础段（每张必带，一字不改）：**

> 游戏建筑资产插画，俯视 3/4 视角（斜 45 度俯瞰）：{建筑描述}。建筑是画面绝对主体，居中，整体轮廓清晰；四周仅有少量草地作为环境，背景干净简洁。画面中没有人物、没有军队、没有文字、没有 UI 元素。柔和光照从左上方照射，主体大小占画面约 70%，方形构图。

**像素风风格段（C2 路线，medium 档）：**

> 艺术风格：高质量复古像素艺术（pixel art）——16/32 位复古策略游戏视觉语言，清晰像素轮廓，克制配色，像素颗粒感明显，小尺寸下依然有高识别度，像高质量复古策略游戏的地图建筑精灵图。**等距视角、军绿底色、木栅栏样式与已完成的「兵营 Lv1」保持一致。**

**绘本风风格段（A 路线，high 档）：**

> 艺术风格：精致的手绘策略桌游绘本插画——柔和厚涂，羊皮纸、木材、石材、铜金材质感，森林绿与砖红暖色系，轻微纸张纹理与绘本质感，墨线勾勒轮廓，像一张精致中世纪策略桌游卡牌上的建筑插画。精致但不过度写实。

**{建筑描述} 素材库**（各建筑的差异描述，已定稿）：
- 兵营：木质结构主楼带清晰坡屋顶，屋顶小旗帜，旁有小型训练场（木桩与草靶）、武器架，矮木栅栏围出小院子
